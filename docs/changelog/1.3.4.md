# BeaverDeck 1.3.4

`BeaverDeck 1.3.4` is a deployment compatibility release for Kubernetes ingress paths.

## Fixed

- fixed UI asset loading, API requests, OAuth redirects, and exec websocket URLs when BeaverDeck is served behind a non-root ingress path such as `/beaverdeck`
- fixed the Helm chart to pass `ingress.path` to the application as `BASE_PATH` when ingress is enabled

## Changed

- frontend production assets are now emitted with relative paths so the same build works at `/` and under a path prefix

## Deployment Notes

- app version: `1.3.4`
- Helm chart version: `2.0.4`
- no chart breaking changes in this release
- when `ingress.enabled` is `true`, the chart sets `BASE_PATH` from `ingress.path`; when ingress is disabled, `BASE_PATH` is `/`
