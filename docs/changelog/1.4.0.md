# BeaverDeck 1.4.0

`BeaverDeck 1.4.0` is a UI, identity, and security hardening release.

## Added

- added Azure Entra ID sign-in support through the existing OIDC flow
- added Microsoft Graph group lookup for Entra ID users using `/me/transitiveMemberOf`
- added Entra group-to-role mapping support by group object ID, display name, mail address, or security identifier
- added local backend development support through `KUBECONFIG` or `~/.kube/config`
- added Vite dev proxying for `/api`, `/healthz`, and WebSocket traffic to the local backend

## Changed

- redesigned the UI with a lighter, faster, square-edged interface
- changed the primary UI accent from green to blue tones to better match BeaverDeck branding
- changed namespace navigation to an always-visible scrollable list with a single `Select all` checkbox
- separated generic OpenID Connect and Azure Entra ID configuration into distinct admin sections
- updated frontend dependencies to React 19, Vite 8, and lucide-react icons
- updated the Docker build image to Go 1.26.3
- updated backend dependencies including Kubernetes client-go 0.36, OAuth2 0.36, and modernc SQLite 1.50
- updated `golang.org/x/net` and related Go modules for current HTTP/2 security fixes

## Fixed

- fixed password visibility buttons inheriting primary form button styling on the initialization screen
- fixed case-sensitive OIDC group matching so mapped external groups resolve reliably
- removed stale namespace popover state after making namespace selection always visible

## Deployment Notes

- app version: `1.4.0`
- Helm chart version: `2.1.0`
- Go 1.26.3 or newer is required for local/release builds
- Azure Entra ID requires an issuer URL such as `https://login.microsoftonline.com/<tenant-id>/v2.0`
- for Entra Graph group lookup, include `User.Read` and `GroupMember.Read.All` in OIDC scopes and grant the required Microsoft Graph consent
