# BeaverDeck 1.4.1

`BeaverDeck 1.4.1` is a patch release focused on exec terminal behavior, Insights navigation, and authentication configuration polish.

## Changed

- split Audit Insights into separate Nodes, Workloads, Networking, and Storage navigation entries
- changed Insights loading so each category requests only the Kubernetes data it needs
- changed Insights resource and log actions to switch to the matching resource tab before opening the dock item
- changed auth configuration test results to use the same bottom toast style as Apply YAML
- changed the profile theme selector to use BeaverDeck UI controls instead of the browser-native select
- changed configured authentication sections to use the shared blue highlight style

## Fixed

- fixed pod exec terminal resize propagation so long commands wrap onto the next terminal row correctly
- fixed exec terminal font spacing regressions
- fixed OpenID Connect and Azure Entra ID configuration dialogs sharing draft state while editing
- fixed OpenID Connect and Azure Entra ID fields such as scopes, email claim, and groups claim being overwritten by provider defaults while opening dialogs
- fixed configured provider badges using the old green success color instead of the blue theme accent
- fixed Local Users and Roles not showing as preconfigured in the admin auth settings

## Deployment Notes

- app version: `1.4.1`
- Helm chart version: `2.1.1`
- this release does not require database migrations
- existing OpenID Connect and Azure Entra ID configuration is stored in the same backend OIDC provider slot; the UI now keeps their edit flows separate and avoids overwriting fields while opening configuration dialogs
