# BeaverDeck 1.5.1

`BeaverDeck 1.5.1` is an Insights documentation, security, and maintenance release.

## Added

- added a `Learn why:` action to Insight cards that opens the BeaverDeck website with documentation explaining what the detected issue means and how to fix it

## Security

- updated the Go build toolchain and Docker build image to Go `1.26.5`
- addressed Go stdlib CVE-2026-39822 and CVE-2026-42505 by moving from Go `1.26.4` to Go `1.26.5`

## Deployment Notes

- app version: `1.5.1`
- Helm chart version: `2.2.2`
- no Helm value was removed
- the default image tag is now `1.5.1`
