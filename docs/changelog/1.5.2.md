# BeaverDeck 1.5.2

`BeaverDeck 1.5.2` is a Go dependency security release.

## Security

- updated `golang.org/x/net` from `0.55.0` to `0.56.0` to address CVE-2026-46600
- updated `golang.org/x/text` from `0.37.0` to `0.39.0` to address CVE-2026-56852, including the invalid UTF-8 `norm.Iter` infinite-loop fix
- refreshed related Go extension modules, including `golang.org/x/sys` `0.46.0` and `golang.org/x/term` `0.44.0`

## Deployment Notes

- app version: `1.5.2`
- Helm chart version: `2.2.3`
- no Helm value was removed
- the default image tag is now `1.5.2`
