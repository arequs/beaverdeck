# BeaverDeck 1.5.3

`BeaverDeck 1.5.3` is a permission-hardening and user-interface maintenance release.

## Security

- changed `secrets: view` to metadata-only list access
- Secret manifests now require `secrets: edit` because their base64 values expose the complete Secret data
- decoded Reveal continues to require `secrets: edit`, while Secret deletion requires `secrets: full`
- added backend regression coverage for normal and decoded Secret manifest requests made by list-only roles

## Changed

- action icon and action-menu tooltips now use a consistent 400 ms hover delay
- disabled action tooltips continue to explain the missing permission or unavailable state
- removed ineffective non-admin `users` and `roles` entries from the role editor because those APIs require `mode: admin`
- clarified that pod manage permission includes eviction and that pod exec also requires pod view permission
- updated React and React DOM to `19.2.8`, lucide-react to `1.26.0`, and Vite to `8.1.5`

## Fixed

- fixed long unbroken log content, including URLs and serialized payloads, expanding the bottom log frame horizontally
- fixed the Secret Manifest action being available to roles with only List Secrets permission

## Deployment Notes

- app version: `1.5.3`
- Helm chart version: `2.2.4`
- no Helm value was added or removed
- the default image tag is now `1.5.3`
- existing roles with `secrets: view` retain Secret metadata listing but must be granted `secrets: edit` to open manifests
