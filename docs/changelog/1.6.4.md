# BeaverDeck 1.6.4

`BeaverDeck 1.6.4` is a security and dependency maintenance release. It replaces the Go release-candidate toolchain
and updates the backend and frontend dependency stacks without changing BeaverDeck product behavior.

## Security

- updated the build toolchain and container build image from Go `1.27rc3` to stable Go `1.27.2` for the current
  standard-library security fixes, including the reported HTTP, TLS, and HTTP/2 findings
- updated `golang.org/x/net` from `0.56.0` to `0.61.0`, newer than the first fixed `0.60.0` release for the reported
  HTTP/2 issues
- updated `golang.org/x/text` from `0.39.0` to `0.43.0`, newer than the first fixed `0.41.0` release for
  CVE-2026-56851

## Changed

- updated Kubernetes Go modules from `0.36.3` to `0.37.1`
- updated `modernc.org/sqlite` from `1.56.0` to `1.60.1`
- updated `golang.org/x/oauth2` from `0.36.0` to `0.37.0`
- updated React and React DOM from `19.2.8` to `19.3.0`
- updated `lucide-react` from `1.26.0` to `1.54.0`
- updated Vite from `8.1.5` to `8.3.4`
- refreshed compatible transitive Go and npm dependencies

## Deployment And Upgrade Notes

- app version: `1.6.4`
- Helm chart version: `2.2.9`
- default image tag: `1.6.4`
- no database migration is required
- no Helm values or runtime configuration changes are required
