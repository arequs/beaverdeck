# BeaverDeck 1.6.5

`BeaverDeck 1.6.5` is a security maintenance release. It updates the Go build toolchain and compatible dependencies
without changing BeaverDeck product behavior or its public API.

## Security

- updated the module and container build baseline to Go `1.27.4`
- updated `golang.org/x/net` to `0.63.0`, newer than the first fixed `0.62.0` release for the reported findings
- refreshed compatible stable Go and frontend dependencies without changing product APIs or configuration
- addresses CVE-2026-111943 / GO-2026-6809 in the standard-library `crypto/x509` package
- includes the upstream denylist used by `crypto/x509.Certificate.Verify` for known intermediate certificates that
  are no longer considered trustworthy

## Compatibility

- no BeaverDeck API, configuration, Helm value, database schema, or authentication method changes
- existing Kubernetes, OIDC, Entra ID, Google OAuth, local-user, and RBAC behavior is unchanged
- dependency updates remain within compatible major-version lines and require no application API changes

## Deployment And Upgrade Notes

- app version: `1.6.5`
- Helm chart version: `2.2.12`
- default image tag: `1.6.5`
- no database migration is required
- no Helm values or runtime configuration changes are required
