# BeaverDeck 1.6.5

`BeaverDeck 1.6.5` is a security maintenance release. It updates the Go build toolchain without changing BeaverDeck
product behavior or its public API.

## Security

- updated the module and container build baseline from Go `1.27.2` to Go `1.27.3`
- addresses CVE-2026-111943 / GO-2026-6809 in the standard-library `crypto/x509` package
- includes the upstream denylist used by `crypto/x509.Certificate.Verify` for known intermediate certificates that
  are no longer considered trustworthy

## Compatibility

- no BeaverDeck API, configuration, Helm value, database schema, or authentication method changes
- existing Kubernetes, OIDC, Entra ID, Google OAuth, local-user, and RBAC behavior is unchanged
- Go dependency module versions are unchanged; the security fix is supplied by the Go standard library

## Deployment And Upgrade Notes

- app version: `1.6.5`
- Helm chart version: `2.2.10`
- default image tag: `1.6.5`
- no database migration is required
- no Helm values or runtime configuration changes are required
